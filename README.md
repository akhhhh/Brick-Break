# Brick-Break
# 🧱 Breakout Game

A classic **Breakout (Brick Breaker)** game built using **HTML5 Canvas, CSS, and JavaScript**. Control the paddle, bounce the ball, break all the bricks, and achieve the highest score!

## 🎮 Features

- Smooth paddle movement
- Ball and brick collision detection
- Score tracking
- Game Over screen
- Restart functionality
- Lightweight and browser-based

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- HTML5 Canvas

## 🚀 How to Play

1. Clone this repository:
   ```bash
   git clone https://github.com/akhhhh/breakout-game.git
   ```

2. Open the project folder.

3. Run `index.html` in your browser.

## 🎯 Controls

| Key | Action |
|-----|--------|
| ⬅️ Left Arrow | Move Left |
| ➡️ Right Arrow | Move Right |
| Space | Restart Game |
